# SALES-DATA-ANALYSIS--POWER-BI

This assignment involved importing and cleaning sales data using Power Query Editor, creating visualizations using Power BI and performing DAX calculations. The pie chart, column chart and line chart helped analyse regional orders, popular products and profit trends. DAX calculations were used to create a filtered table, a calculated column and a measure. Overall, the assignment provided practical experience in data cleaning, data visualization and data analysis using Power BI.
